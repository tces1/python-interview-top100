# Python Interview Top 100

一份可以真正刷完的中文 Python 面试高频题库。覆盖基础语法、数据结构、函数与迭代、面向对象、工程实践、并发与性能、测试与类型、编码实战 8 个专题。

## 功能

- 100 道题均包含结论、详细讲解、关键点、示例代码、可能追问及追问参考答案
- 按专题、难度、学习状态筛选，支持全文搜索
- 收藏题目、标记已掌握，进度保存在浏览器本地
- 随机抽题、继续学习、题目永久链接和一键复制代码
- 响应式布局、深浅色主题、键盘与无障碍支持
- 纯 HTML / CSS / JavaScript，无构建依赖

## 本地查看

直接用浏览器打开 `index.html`，或在项目目录启动任意静态文件服务器：

```bash
python -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 选题方法

题目参考多份公开面试题单中反复出现的主题，并以 Python 官方文档核对容易答错的语言行为。Top 100 是编辑整理结果，不代表招聘平台的精确频次统计。

主要参考：

- [Python Programming FAQ](https://docs.python.org/3/faq/programming.html)
- [Python Descriptor Guide](https://docs.python.org/3/howto/descriptor.html)
- [Python Free-threading Guide](https://docs.python.org/3/howto/free-threading-python.html)
- [DataCamp · Top Python Interview Questions](https://www.datacamp.com/blog/top-python-interview-questions-and-answers)
- [GeeksforGeeks · Python Interview Questions](https://www.geeksforgeeks.org/python/python-interview-questions/)
- [Real Python · Interview Learning Path](https://realpython.com/learning-paths/python-interview/)

最后核对：2026 年 11 月。
